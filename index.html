WTX

Open file format · Web & mobile app

Active

A dead-simple, plain-text format for strength training: .wtt files for routines and .wts files for logged sessions, readable and writable by hand. The companion app is mobile-first and local-first.

  • Build routines with a form that serializes back to valid .wtt.
  • Share a whole routine through a QR code or a self-contained link.
  • Log sessions with a rest timer, live PR detection and a training calendar.
  • Optional sync and live group workouts with friends.
  • TypeScript
  • Vue 3
  • Pinia

  • Vitest
  • Supabase
